# Bundled languages

English is the source language. Italian, Russian and Spanish catalogues are embedded in the executable and available without a translation server, including in setup. They cover navigation, common controls, accounts, skin controls and the new setup errors. Technical and advanced messages not yet translated fall back to English. A complete local `.po` catalogue in the translations directory takes priority.

The `Common` context supplies shared labels; an exact context always takes priority. Keep `%1` placeholders intact. These translations are part of XylarJava under GPL-3.0-only.
